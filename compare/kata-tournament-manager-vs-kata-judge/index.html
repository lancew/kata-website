Judo Kata Tournament Manager vs Judo Kata Judge

Both are free, open-source (AGPL) tools for judo kata. The real difference is scope and where they run: one is an IJF-ruleset judging app on a cloud database, the other is an all-in-one event system that runs offline on a laptop.

TL;DR

Judo Kata Judge is a focused IJF kata judging web app that stores its data in an Azure cloud database. Judo Kata Tournament Manager runs an entire kata event — draw, judge tablets, live hall results, printable packs — offline on a laptop. If you only need IJF judging and can host on Azure, Judo Kata Judge is a reasonable fit. If you need the whole event, offline, and EJU or BJA-style scoring too, this is built for that.

In detail

Scope: judging app vs event system

Judo Kata Judge is about judging. Its data model is judges, tournaments, and matches, and it scores to the IJF ruleset. Judo Kata Tournament Manager covers the whole event: registering competitors and judges, running the draw, seating panels, scoring on tablets, displaying results, and producing the paperwork.

Bottom line: if you already have a process for the draw and displays and only need judging, a focused app can be enough. If you want to replace the spreadsheet and the manual displays, you need the broader system.

Offline and venue networks

Judo Kata Judge stores data in Azure Cosmos DB, so it assumes internet access and a cloud account. Judo Kata Tournament Manager runs entirely on a laptop on the venue LAN, needs no account, and keeps each event in a local SQLite file.

Bottom line: for venues with poor or no internet — which is common — an offline system removes the biggest single risk.

Rulesets

Judo Kata Judge implements the IJF ruleset. Judo Kata Tournament Manager implements EJU, kata-judge/BJA-style, and IJF, validated against the senior categories of the 2024 Silesian Open Judo Kata Competition.

Bottom line: if all your events are IJF, either works. If you handle EJU or BJA-style events, the extra rulesets matter.

Judge and hall experience

Both let judges score on a screen. Judo Kata Tournament Manager adds named seats with immediate saving, submit and unsubmit, shadow seats, and a mat clerk view, and it drives a live hall results screen and an announcer board.

Bottom line: the hall display is the feature organisers and spectators notice most.

Data and cost

Both are AGPL. Judo Kata Judge needs Azure resources, which carry a running cost and a setup step; Judo Kata Tournament Manager runs on a laptop at no cost, with paid on-site or hardware options if you want someone to run it for you.

Bottom line: “free” software is not always free to operate. Factor in the cloud account.

Who each is for

Choose Judo Kata Tournament Manager if…

  • You want one offline system for the whole event
  • You need EJU or BJA-style scoring as well as IJF
  • You want live results and an announcer board for the hall
  • You want the organiser to own the data with no cloud account

Choose Judo Kata Judge if…

  • You only need IJF-ruleset judging
  • You are happy hosting on Azure and managing the account
  • You already have the draw and displays covered elsewhere
  • You want a small, focused web app to self-host

Questions

What is the difference between Judo Kata Tournament Manager and Judo Kata Judge?

Judo Kata Judge is an IJF-ruleset judging web app built on an Azure cloud database. Judo Kata Tournament Manager is an all-in-one event system that runs offline on a laptop on the venue network, covering the draw, judge tablets, live hall results, and printable packs, with EJU, kata-judge/BJA-style, and IJF rulesets.

Can Judo Kata Judge run without internet?

It is designed around Azure Cosmos DB cloud storage, so it is not built for an offline venue LAN. Judo Kata Tournament Manager runs fully offline on the venue network.

Are both free and open source?

Yes, both are AGPL-licensed. Judo Kata Judge needs Azure resources to run, which have a running cost; Judo Kata Tournament Manager runs on a laptop with no running cost.
