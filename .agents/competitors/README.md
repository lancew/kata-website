## Landscape summary
- **Direct:** Judo Kata Judge is the only close named competitor — judging-only and cloud-based.
- **Secondary:** the Excel EJU scoresheets most organisers use today.
- **Indirect:** paper scoresheets + manual tally; generic spreadsheets; generic event software that does not handle kata panels.
