venue systems, membership, Revolutionise exports, flag ceremonies — with kata
scorecards as one small area.

- **Platform:** Windows desktop / .NET; not a LAN browser system
- **Offline / LAN tablet judging:** not evidenced
- **Live hall display for kata scoring:** not evidenced

## Strengths (be fair)
- Very broad judo domain coverage
- Free and open source (MIT)
- Real-world provenance (used by a club/event developer)

## Weaknesses
- Windows-only desktop tooling; not device-agnostic
- Kata scoring is a small part of a large, fragmented codebase
- No evidence of browser tablets, live hall results, or an offline LAN event system
- No packaged product, documentation, or support

## Best for
- Windows-based clubs/events wanting assorted judo utilities from source

## Not ideal for
- Organisers wanting a single, supported kata competition system with judge tablets and hall displays
